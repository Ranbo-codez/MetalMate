# Security

MetalMate takes screenshots of the window you choose and runs chess engines on your Mac, so security
problems matter.

**Please report security problems privately**, not as a public issue:
[report a vulnerability](https://github.com/Ranbo-codez/MetalMate/security/advisories/new).
Include what you found, how to reproduce it and which version you used.

Only the latest release gets security fixes. Download MetalMate only from this repository's
[Releases](https://github.com/Ranbo-codez/MetalMate/releases) page; copies from anywhere else may have
been changed. Each release lists the SHA-256 of its DMG so you can check your download:

```bash
shasum -a 256 ~/Downloads/MetalMate.dmg
```
